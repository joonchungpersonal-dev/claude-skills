# Nielsen's 10 Usability Heuristics — Scoring Rubric

For each heuristic, score 0-4. Total = sum / 40 * 100.

## H1: Visibility of System Status (0-4)
- 4: Clear loading states, progress indicators, current location always visible
- 3: Most states communicated, minor gaps
- 2: Some states missing (e.g., no loading indicator)
- 1: User frequently unsure what's happening
- 0: No system status feedback

## H2: Match Between System and Real World (0-4)
- 4: Language matches user's domain, logical ordering, familiar concepts
- 3: Mostly clear, occasional jargon
- 2: Mix of clear and confusing terminology
- 1: Heavily technical/unfamiliar language
- 0: Incomprehensible to target user

## H3: User Control and Freedom (0-4)
- 4: Undo/redo, clear exits, back navigation, cancel options
- 3: Most actions reversible, minor gaps
- 2: Some trapped states
- 1: Frequently trapped, hard to recover
- 0: No way to undo or escape

## H4: Consistency and Standards (0-4)
- 4: Consistent patterns, follows platform conventions
- 3: Minor inconsistencies
- 2: Noticeable inconsistencies in styling or interaction
- 1: Inconsistent throughout
- 0: No discernible pattern

## H5: Error Prevention (0-4)
- 4: Confirmation dialogs, input validation, safe defaults
- 3: Most errors prevented
- 2: Some common errors not prevented
- 1: Easy to make mistakes
- 0: Error-prone design

## H6: Recognition Rather Than Recall (0-4)
- 4: All options visible, good labels, no memorization needed
- 3: Most information visible when needed
- 2: Some hidden options requiring recall
- 1: Heavy reliance on memory
- 0: Must memorize to use

## H7: Flexibility and Efficiency (0-4)
- 4: Keyboard shortcuts, search, filters, power-user paths
- 3: Some efficiency features
- 2: Basic functionality only
- 1: Tedious for repeated tasks
- 0: No efficiency features

## H8: Aesthetic and Minimalist Design (0-4)
- 4: Clean, focused, no clutter, good hierarchy
- 3: Mostly clean, minor clutter
- 2: Some unnecessary elements
- 1: Cluttered, hard to scan
- 0: Overwhelming visual noise

## H9: Help Users Recognize and Recover from Errors (0-4)
- 4: Clear error messages, suggested fixes, graceful degradation
- 3: Error messages present, mostly helpful
- 2: Generic error messages
- 1: Cryptic errors
- 0: Silent failures or crashes

## H10: Help and Documentation (0-4)
- 4: Contextual help, tooltips, searchable docs
- 3: Some help available
- 2: Minimal help
- 1: Help exists but unhelpful
- 0: No help or documentation
